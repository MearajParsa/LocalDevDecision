# پروژه شخصی من: LocalDevDecision 🚀

سلام! به پروژه `LocalDevDecision` من خوش اومدید! این اولین قدم من برای ساخت یه دستیار هوشمند و محلی برای برنامه‌نویسیه.
هدفم این بود که یه سیستمی بسازم که وقتی به مشکلی تو کد می‌خوریم یا می‌خوایم یه کاری انجام بدیم، به جای اینکه متن‌های طولانی بهمون تحویل بده، سریعاً بهمون بگه قدم بعدی چیه. خروجی این سیستم خیلی تمیز و به شکل ساختاریافته (JSON) تولید میشه.

مهم‌ترین ویژگی این پروژه اینه که **کاملاً محلی (Local)** و سبک اجرا میشه. یعنی نه نیاز به اینترنت دارید، نه به GPU و نه به APIهای گرون قیمت.

## چه فرقی بین آموزش و اجرا هست؟ 🧠
اگه با هوش مصنوعی کار نکرده باشید، ممکنه براتون سوال بشه. روند کار من اینجوریه:
- **آموزش (Training):** من به مدل یه عالمه مثال (در قالب یه فایل) می‌دم که یاد بگیره توی هر شرایطی چه تصمیمی باید بگیره. این مرحله مدل رو می‌سازه.
- **اجرا (Inference):** بعد از اینکه مدل یاد گرفت، روی سیستم ذخیره میشه و دیگه فقط کافیه ازش استفاده کنیم! توی کسری از ثانیه جواب می‌ده.

## چطوری پروژه‌م رو اجرا کنی؟ 🛠️

اول از همه مطمئن شو که پایتون ۳.۱۲ رو سیستمت نصبه.

### ۱. محیط مجازی رو بسازیم
بهتره که یه محیط ایزوله بسازیم تا کتابخونه‌های این پروژه با بقیه پروژه‌ها تداخل نداشته باشه. توی ترمینال اینا رو بزن:
```bash
# ساخت محیط مجازی
python -m venv venv

# فعال‌کردنش تو ویندوز
venv\Scripts\activate
# (اگه لینوکس یا مک هستی: source venv/bin/activate)
```

### ۲. نصب ابزارهای لازم
حالا وقتشه که کتابخونه‌ها رو نصب کنیم:
```bash
pip install -r requirements.txt
# اگه می‌خوای تست‌ها رو هم ران کنی، اینم نصب کن:
pip install -r requirements-dev.txt
```

### ۳. آموزش مدل (مرحله جذاب!)
یه فایل به اسم `data/decisions.csv` شامل دیتای تست تو پروژه هست که باهاش مدل رو آموزش می‌دیم. فقط کافیه این دستور رو بزنی:
```bash
python train.py
```
مدل که آموزش دید، تو پوشه `artifacts` ذخیره میشه.

### ۴. چطوری از مدل استفاده کنیم؟ (اپلیکیشن ترمینالی 💻)
من یه اپلیکیشن خیلی باحال و خوشگل برای ترمینال نوشتم. برای اجرای دستیار، فقط اینو بزن:
```bash
python app.py
```
حالا می‌تونی سوال یا وضعیتت رو (فارسی یا انگلیسی) تایپ کنی تا مدل بهت بگه اقدام مناسب بعدی چیه! برای خروج هم می‌تونی `quit` یا `exit` رو تایپ کنی.

### ۵. می‌خوای خروجی خام (JSON) رو ببینی؟
اگه خواستی از این ابزار توی اسکریپت‌های دیگه‌ت استفاده کنی، می‌تونی از نسخه خط فرمان (CLI) قبلی استفاده کنی:
```bash
python predict.py --context "من خطای NameError دارم"
```

## چندتا نکته دیگه 📌
- برای تست سرعت مدل می‌تونی `python benchmark.py` رو ران کنی.
- اگه می‌خوای مطمئن بشی که تغییری که دادی چیزی رو خراب نکرده، `pytest` رو اجرا کن.
- این مدل فقط **پیشنهاد** می‌ده و هیچ فایلی از شما رو خودش تغییر نمی‌ده.

امیدوارم از این پروژه لذت ببرید! اگه پیشنهادی برای بهتر شدنش دارید خوشحال میشم بهم بگید.
