# پروژه LocalDevDecision

## ۱. معرفی و هدف پروژه
به اولین پروژه هوش مصنوعی خود خوش آمدید! `LocalDevDecision` یک سیستم تصمیم‌گیرنده هوشمند است که به جای تولید متن‌های طولانی و پیچیده، با بررسی وضعیت مسئله برنامه‌نویسی شما، اقدام مناسب بعدی را به صورت یک خروجی ساختاریافته (JSON) پیشنهاد می‌دهد.
هدف اصلی این پروژه، اجرای فوق‌العاده سریع و **کاملاً محلی** است، بدون نیاز به اینترنت، GPU یا API‌های خارجی.

## ۲. تفاوت آموزش مدل و اجرای مدل
در یادگیری ماشین، فرایند کار به دو بخش اصلی تقسیم می‌شود:
- **آموزش مدل (Training):** در این مرحله، ما به سیستم هزاران نمونه تصمیم‌گیری قبلی را در قالب یک "دیتاست" می‌دهیم تا الگوها را یاد بگیرد و یک فایل فشرده به نام مدل بسازد. این فرایند ممکن است کمی زمان ببرد و به کتابخانه‌ها و داده‌های بیشتری نیاز دارد.
- **اجرای مدل (Inference / Prediction):** پس از آموزش، مدل آماده است تا در کسری از ثانیه روی داده‌های جدید تصمیم‌گیری کند. در این مرحله نیازی به دیتاست اصلی نیست و فقط فایل مدل بارگذاری می‌شود.

## ۳. پیش‌نیازها
- سیستم‌عامل: Windows (یا Linux)
- نصب بودن **Python 3.12** روی سیستم.
- حداقل رم ۱۶ گیگابایت برای سیستم برنامه‌نویس (استفاده مدل بسیار کمتر از این مقدار است).
- بدون نیاز به اینترنت برای استفاده.

## ۴. نصب روی Windows و ایجاد محیط مجازی
استفاده از محیط مجازی (Virtual Environment) باعث می‌شود وابستگی‌های این پروژه با سایر پروژه‌های سیستم شما تداخل پیدا نکند.
مراحل زیر را در ترمینال (مثل PowerShell یا Command Prompt) در پوشه پروژه اجرا کنید:

```bash
# ایجاد محیط مجازی
python -m venv venv

# فعال‌سازی محیط مجازی در ویندوز
venv\Scripts\activate
# (در لینوکس: source venv/bin/activate)
```

## ۵. نصب وابستگی‌ها
پس از فعال‌سازی محیط مجازی، بسته‌های مورد نیاز را نصب کنید:
```bash
pip install -r requirements.txt
# در صورت نیاز به اجرای تست‌ها، ابزارهای توسعه را نیز نصب کنید:
pip install -r requirements-dev.txt
```

## ۶. طراحی دیتاست و افزودن نمونه
برای آموزش مدل، به یک فایل دیتاست در مسیر `data/decisions.csv` نیاز دارید. این فایل باید با فرمت CSV و شامل دو ستون `context` و `label` باشد.
اگر این فایل موجود نباشد، می‌توانید از فایل نمونه `data/decisions.example.csv` الگو بگیرید و نمونه‌های واقعی خود را بسازید. برای دقت بالا به صدها یا هزاران نمونه متنوع نیاز است.

## ۷. آموزش مدل
برای آموزش مدل روی داده‌های خودتان دستور زیر را اجرا کنید:
```bash
python train.py
```
در صورت موفقیت، مدل در پوشه `artifacts/` ذخیره می‌شود و گزارش دقت آن چاپ خواهد شد.

## ۸. ارزیابی مدل و سنجش سرعت
برای سنجش سرعت بارگذاری و پیش‌بینی مدل، اسکریپت زیر را اجرا کنید:
```bash
python benchmark.py
```
این اسکریپت زمان لازم برای بارگذاری و پیش‌بینی‌های مدل را محاسبه می‌کند (معمولاً سرعت پیش‌بینی کمتر از ۱ ثانیه خواهد بود).

## ۹. اجرای پیش‌بینی
برای دریافت پیشنهاد اقدام بعدی براساس وضعیت فعلی کد، می‌توانید از حالت خط فرمان (CLI) استفاده کنید:
```bash
python predict.py --context "language: python; error: NameError; previous_action: inspect_error"
```
سیستم یک خروجی JSON شبیه به این به شما برمی‌گرداند:
```json
{
  "action": "search_code",
  "score": 0.82,
  "status": "needs_review",
  "review_required": true
}
```

## ۱۰. اجرای تست‌ها
برای اطمینان از سلامت کدهای پروژه، دستور زیر را اجرا کنید:
```bash
pytest
```

## ۱۱. محل ذخیره مدل و انتقال آن به کامپیوتر دیگر
مدل آموزش دیده در مسیر `artifacts/decision_model.joblib` ذخیره می‌شود.
برای استفاده از این سیستم در یک کامپیوتر دیگر، تنها کافیست:
1. فایل `predict.py` و `decision_engine.py` را همراه با فایل مدل به سیستم مقصد منتقل کنید.
2. بسته‌های موجود در `requirements.txt` را در سیستم مقصد نصب کنید.
3. **دیگر نیازی به کدهای تست، دیتاست و اسکریپت آموزش ندارید.**

## ۱۲. اجرای آفلاین
این مدل به گونه‌ای طراحی شده که هیچ وابستگی شبکه‌ای ندارد. تمامی کتابخانه‌ها و مدل‌ها به‌طور محلی پردازش می‌شوند.

## ۱۳. رفع خطاهای متداول
- **خطای FileNotFoundError هنگام پیش‌بینی:** مدل هنوز آموزش ندیده است. ابتدا فایل داده‌های خود را در `data/decisions.csv` قرار دهید و `python train.py` را اجرا کنید.
- **خطای Dataset Invalid:** ساختار فایل CSV شما اشتباه است. مطمئن شوید دارای هدرهای `context` و `label` باشد.
- **خطای رم یا کمبود حافظه (MemoryError):** اگر چه مدل بسیار سبک است، اما در زمان آموزش دیتاست‌های بسیار بزرگ ممکن است پیش بیاید.

## ۱۴. محدودیت‌های فعلی مدل
- این مدل **اقدامات را روی فایل‌های شما اجرا نمی‌کند**؛ فقط اقدام مناسب را به عنوان خروجی متنی پیشنهاد می‌دهد.
- قدرت تشخیص مدل وابستگی مستقیم به تنوع و کیفیت داده‌هایی دارد که در مرحله آموزش به آن می‌دهید.
- درک ساختار معنایی عمیق کدها در این نسخه محدود به پیش‌پردازش‌های مبتنی بر کلمات و کاراکترها است.

## ۱۵. قابلیت‌های پیشنهادی برای مراحل آینده
- اتصال خروجی سیستم به ابزارهای خودکارساز برای اجرای واقعی دستورات.
- ارتقاء مدل استخراج ویژگی به Sentence Transformers.
- استفاده از فرمت ONNX برای استنتاج سریع‌تر در صورت نیاز.
